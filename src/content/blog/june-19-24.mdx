# PoroScout Update - June 2nd :porohappy:

## :up: Patchnotes command improvements!

You can now lookup older patches with </patchnotes:914155176061972480>'s the new `version` field. For example, `/patchnotes version: 12.3` will give you the description for patch 12.3! Any patch past season the 2019 season is supported!

This update also resolves the previously issued status update at https://discord.com/channels/763556769652932651/916445945854566431/1245802777259540720
You can expect your regularly scheduled patch notes in #📝・league-patch-notes or with </configure patchnotes:920459734757277696> again.

There are a few other small changes to the patchnotes command:

- A short fun blurb has been added to the footer (ie Patch 14.11 is a scorcher. :fire:).
- Text formatting is now preserved for the description, so the tft links will now work and italics will show properly.

## :new: Ranked icons updated!

PoroScout ranked icons have been upgraded from their old images (:GOLD:), and emerald rank is now properly recognized.

## :cinema: Live command fixed

</live:914530388473417759> and the `Current Game` field in </profile:913214567826456619> have been broken for a while since Riot removed the old endpoint PoroScout used. I've updated PoroScout to use the latest endpoint and both of these features are now functional again!
