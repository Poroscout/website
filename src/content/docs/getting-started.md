Welcome to **PoroScout**, your League of Legends scouting companion for Discord. This guide gets you from zero to your first command in under a minute.

## Add PoroScout

You can add PoroScout two ways:

- **To a server**: great for communities. You'll need the **Manage Server** permission. Everyone in the server can use PoroScout's slash commands.
- **To your account**: PoroScout follows you into DMs, group chats, and any server, even ones it hasn't been added to.

Use the **Add to Discord** button at the top of [poroscout.gg](/), or the options in the invite section.

## Run your first command

PoroScout is entirely slash-command driven. In any channel where it's available, type `/` and start typing `poroscout` or a command name.

Try these to get a feel for it:

```text
/champion name:Ahri
/profile region:NA1 summoner:Hide on bush
/patchnotes
```
