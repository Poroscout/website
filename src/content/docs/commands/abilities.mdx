# Usage

```text
/abilities champion:<champion>
```

| Argument   | Required | Description                                    |
| ---------- | -------- | ---------------------------------------------- |
| `champion` | Yes      | The name of the champion to get abilities for. |

# Description

Use the select menu at the bottom to choose between sections: Overview, Q, W, E, R abilities, the champion's Passive, and tips.

The overview page provides a brief about the champion's lore and base stats like HP, HP Regen, Mana, Mana Regen, Attack Damage, Attack Speed, Crit Chance, Attack Range, Movement Speed, Armor, and Magic Resist.

Each ability section (Q, W, E, R and Passive) includes:

- The name of the ability
- The description of the ability
- Cooldown and mana/resource cost if applicable
- Scaling information
- Description of any active effects or passives for the ability

The tips section will provide some, albeit general, tips on how to play against or as the champion.

# Extra Information

Champions with multiple forms (i.e. Nidalee) will have multiple embeds per ability, one for each form. This allows you to see the abilities for each form of the champion.
